## Formato

Cada ADR contiene: **Estado**, **Fecha**, **Contexto**, **Decisión**, **Alternativas consideradas**, **Consecuencias**.

Si una decisión cambia, el ADR original no se borra: se marca como `Reemplazada por ADR-XXX` y el nuevo indica qué reemplaza y por qué.
